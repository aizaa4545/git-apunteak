GIT: BRANCH ETA MERGE

Ikasi Git-en adarrekin lan egiten

Branch Merge Gatazkak Ariketa

1. Zer da Branch?

Branch (adarra) proiektu baten barruan lan egiteko bide independente bat da.

Adarrei esker, funtzio berriak gara ditzakegu proiektuaren adar nagusia aldatu gabe.

Adibidea

main: Proiektuaren adar nagusia.

diseinua: Diseinua aldatzeko adarra.

login: Saioa hasteko funtzioa sortzeko adarra.

Komando nagusiak

git branch
git branch diseinua
git switch diseinua
git switch -c login
git branch -d diseinua

git branch: dauden adarrak erakusten ditu.

git branch diseinua: adar berri bat sortzen du.

git switch diseinua: beste adar batera aldatzen da.

git switch -c login: adar bat sortu eta bertara aldatzen da.

git branch -d diseinua: adar bat ezabatzen du.

2. Nola funtzionatzen dute adarrek?

Imajinatu proiektu nagusi bat duzula eta funtzio berri bat garatu nahi duzula.

MAIN

● Commit 1 → ● Commit 2 → ● Commit 3

DISEINUA

● Commit 1 → ● Commit 2 → ● Diseinu berria

Adar bakoitzean modu independentean lan egin dezakezu, aldaketak elkartu nahi dituzun arte.

3. Zer da Merge?

Merge-k batzea esan nahi du. Adar bateko aldaketak beste adar batera gehitzeko erabiltzen da.

Adibide praktikoa

Diseinua adarrean lana amaitu duzu eta aldaketa horiek main adarrera gehitu nahi dituzu. 

git add .
git commit -m "Diseinua amaituta"

git switch main

git merge diseinua
GARRANTZITSUA: Merge egin aurretik, aldaketak jasoko dituen adarrean egon behar duzu.

4. Merge gatazkak

Gatazka bat gertatzen da Git-ek ezin duenean automatikoki erabaki zein aldaketa mantendu.

Adibidea

MAIN

izena = "Kaixo"

DISEINUA

izena = "Agur"

Bi adarrek lerro bera aldatu dute. Fitxategia ireki eta zein bertsio mantendu erabaki behar duzu.

5. Branch eta Merge arteko desberdintasunak

BRANCH

Lan egiteko adar independenteak sortzen ditu.

MERGE

Adar desberdinetako aldaketak batzen ditu.
